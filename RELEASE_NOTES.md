## Что это такое

**NTSD (Naruto: The Setting Dawn)** — фанатский файтинг по «Наруто» на движке Little Fighter 2. Игра сделана для Windows, а это её версия для Mac: открывается как обычное приложение.

Внутри уже лежит всё нужное: сама игра, Wine (он запускает Windows-игры на Mac) и всё для музыки. Ничего доустанавливать не надо. Приложение подписано и проверено Apple, так что macOS не будет ругаться при запуске.

## Как установить

1. Скачай **`NTSD-2.8.3.3-macOS.dmg`** внизу, в разделе Assets.
2. Открой его и перетащи **NTSD** в папку «Программы».
3. Запусти NTSD из «Программ» или из Launchpad.
4. Первый запуск занимает около 30 секунд, пока приложение всё готовит. Потом игра открывается сразу.

Если macOS предложит установить **Rosetta** — соглашайся. Без неё на Mac с чипами M1/M2/M3/M4 игра не запустится.

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| Ходить | W A S D | стрелки |
| Атака | J | `,` |
| Прыжок | K | `.` |
| Защита | L | `/` |

Клавиши можно поменять в игре: пункт **CONTROL SETTINGS** в главном меню.

## Полезное

- **Моды, `data.txt`, записи боёв.** Зажми **Option**, когда открываешь NTSD, и выбери «Открыть папку игры».
- **Если что-то сломалось.** Там же есть «Сбросить Wine». Настройки и записи при этом останутся.
- **Системные требования:** macOS 11 или новее.
- **Как удалить:** перетащи NTSD в корзину. Файлы игры лежат в `~/Library/Application Support/NTSD`.

## What is this

**NTSD (Naruto: The Setting Dawn)** is a fan-made Naruto fighting game built on Little Fighter 2. It was made for Windows; this is a Mac version that opens like any other app.

Everything is included: the game, Wine (which runs Windows games on a Mac) and what it needs for music. There's nothing else to install. The app is signed and notarized by Apple, so macOS won't block it.

## How to install

1. Download **`NTSD-2.8.3.3-macOS.dmg`** from Assets below.
2. Open it and drag **NTSD** into Applications.
3. Open NTSD from Applications or Launchpad.
4. The first launch takes about 30 seconds while the app sets things up. After that the game opens right away.

If macOS offers to install **Rosetta**, say yes. Macs with M1/M2/M3/M4 chips need it to run the game.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | W A S D | arrow keys |
| Attack | J | `,` |
| Jump | K | `.` |
| Defend | L | `/` |

You can change them in the game under **CONTROL SETTINGS** in the main menu.

## Good to know

- **Mods, `data.txt`, recordings.** Hold **Option** while opening NTSD and pick "Open Game Folder".
- **If something breaks.** The same menu has "Reset Wine". Your settings and recordings stay.
- **Requirements:** macOS 11 or later.
- **Uninstall:** drag NTSD to the Trash. Game files live in `~/Library/Application Support/NTSD`.

## New in 2.8.3.3.2

Attack, jump and defend no longer default to the numeric keypad, which most Macs don't have. They're now J/K/L, as in the original LF2. If you already changed your keys, the update keeps them.
